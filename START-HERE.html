Deploy and connect editing

  1. Upload the extracted project files to your chosen GitHub repository, preserving the .github folder.
  2. Choose GitHub Actions in the repository's Pages settings.
  3. Follow GitHub and CMS setup to configure the OAuth Worker and approved editor accounts.
  4. Add the approved custom domain when it is ready.
