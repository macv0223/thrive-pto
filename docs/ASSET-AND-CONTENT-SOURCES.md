The correct school website and public PTO-related FutureFund listings were researched. No scraped student photographs or social-post images were republished because their reuse permission was not established. The supplied PTO logo is the website's brand asset.

The website does not repeat the school's medical, therapeutic, academic-results, or enrollment claims. PTO membership benefits remain general because the supplied copy does not enumerate them. No event dates, announcements, board identities, prices, or donation claims were supplied, so those are not fabricated.

## Replacing placeholder imagery

In the editor, open **Website pages → Home**. Upload an approved image, update its image description, and revise the caption. Keep identifying language for temporary artwork until an actual approved image is supplied. The layout supports both the homepage image and optional announcement images.

The website's sources and configuration are separate from approved content. Updates to original source files remain part of their original records; this project contains the organized website copy rather than altering those uploaded files.
